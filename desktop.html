Cómo funciona

1. Pulsa Permitir y activar avisos y acepta el permiso del navegador.

2. Pulsa Probar dentro de 5 segundos y cambia a otro programa.

3. Deja esta ventana abierta, aunque esté minimizada. Al pulsar una notificación volverás aquí para posponer o descartar.

Al cerrar esta ventana se detienen sus recordatorios. El navegador y Windows controlan el sonido y la duración final del aviso. Si no aparece, revisa las notificaciones del navegador en Windows y el modo No molestar.

Esta ventana usa una copia del horario guardado. Mientras el panel de KanBell siga abierto recibirá los cambios que guardes. Si has cerrado el panel, vuelve a pulsar «Activar avisos de Windows» desde KanBell para actualizarla. Posponer o descartar aquí afecta a los avisos de Windows de esta ventana.
